Inconsistencia

El sitio actual no usa los colores del logo

tazcorp.cl/css/colors/default.css define el primario como #2F55D4 y el degradado como #614092. Ninguno de los dos aparece en el logotipo: son los valores de fábrica de la plantilla Bootstrap «Landrick», que nunca se personalizaron. Esta paleta corrige el rumbo tomando el logo como fuente de verdad — es el activo que no se puede cambiar. Actualizar el sitio a estos tokens es el paso pendiente.

Reglas

Lo que hace que se vea Taz

Una paleta no crea reconocimiento; la proporción sí. La misma repartición del logotipo se traslada a la pantalla.

Proporción 60 / 30 / 10

60 · neutro
30 · azul
10

El neutro sostiene la página, el azul manda la acción y el oro aparece una o dos veces por pantalla: el indicador de pestaña activa, el sello de un estado destacado, la línea bajo el título de sección. Si el oro se ve en todas partes, deja de leerse como Taz y empieza a leerse como advertencia.

La firma

  • Azul relleno para la acción primaria; oro relleno solo para la acción destacada de la pantalla.
  • Subrayado o barra lateral en oro sobre encabezados de sección.
  • La espiral como spinner de carga — el arco azul y el dorado girando en sentidos opuestos. Es lo más reconocible que tiene la marca.
  • Sobre fondo oscuro, el oro se mantiene igual; el azul sube al 300 para el texto.

Prohibiciones

  • Degradado azul → oro. Interpolado en sRGB pasa por un verde oliva sucio. Si hace falta degradado, que sea azul 600 → azul 400.
  • Texto dorado sobre blanco. #E8BB2F da 1,8:1 — ilegible. Usa el oro 700.
  • Texto blanco sobre oro. El dorado siempre lleva tinta oscura encima (#1A1F26).
  • El violeta #614092 de la plantilla. No pertenece a la marca.
  • El gris puro #959595 como neutro de interfaz. Se ve muerto junto al azul; queda reservado al wordmark.

Integrar

Llevarlo a cada proyecto

Los archivos ya están escritos en C:\Users\omard\taz-brand\. La regla es que ningún proyecto redefina hexadecimales: todos consumen las variables.

tokens.css
Variables CSS con las tres escalas, semánticos, roles y tema oscuro. Funciona en cualquier stack.
taz.theme.css
Bloque @theme para Tailwind 4 — habilita bg-primary, text-brand-gold-700, etc.
identidad-taz.html
Esta página. Es la referencia viva del sistema.

Proyecto con Tailwind 4 (Angular / React)

/* src/styles.css */
@import "tailwindcss";
@import "../../taz-brand/tokens.css";
@import "../../taz-brand/taz.theme.css";

body { background: var(--taz-bg); color: var(--taz-text); }

Proyecto sin Tailwind (Jinja, Bootstrap, CSS plano)

<link rel="stylesheet" href="/static/taz/tokens.css">

.btn-primary  { background: var(--taz-primary); color: var(--taz-on-primary); }
.btn-primary:hover { background: var(--taz-primary-hover); }
.btn-accent   { background: var(--taz-accent);  color: var(--taz-on-accent); }
a             { color: var(--taz-primary-text); }
.card         { background: var(--taz-surface); border: 1px solid var(--taz-border); }

Orden de adopción

  1. Copiar tokens.css al proyecto (o referenciarlo desde taz-brand/ si comparten disco).
  2. Reemplazar cada hexadecimal suelto del proyecto por la variable equivalente. Un grep -rn "#[0-9a-fA-F]\{6\}" encuentra los rezagados.
  3. Fijar el logotipo: TAZ_LOGO.png en superficies claras, TAZ_LOGO_BLANCO.png sobre azul 700 o más oscuro.
  4. Actualizar tazcorp.cl — es el sitio que hoy contradice su propio logo.
